# v0.7 implementation and verification

## Delivered architecture

- `MainActivity` now hosts modular `platformui` screens. Projects and operations
  survive navigation; UI observes lifecycle-aware repository flows.
- `models`: shared local/remote registry, resource compatibility, routing, real
  resumable model downloads and a filtered model picker in each workspace.
- `remote` / `HuggingFaceSpaceClient`: shared authentication, short Gradio calls,
  pinned per-task Space, provider health, same-job recovery and result downloads.
- `projects` / `storage`: atomic metadata, legacy video migration, CRUD, saved
  draft/source versions, safe asset copies and persistent local outputs.
- `tasks`: durable generic operations, partial text, foreground local inference,
  cancellation notifications, source/media/document exports and recovery.
- `voice`: microphone foreground service plus local Whisper transcription into
  the editable prompt. Speech is independent of the single text-LLM gate.
- `research` / `exports`: section editing/regeneration, actual Crossref metadata,
  manual source records/citation links, structured findings/charts and genuine
  DOCX/PDF/PPTX/XLSX. Images/charts embed in document/presentation/PDF exports.
- `platformui`: Companion, App, Research, Visual and Video projects, global tasks,
  media preview/share/save, image gallery/zoom, model and provider settings.

Major existing changes: `OfflineModels`, `LocalLlmEngine`, `WhisperVoiceEngine`,
`VideoTasks`, `VideoBackendSettings`, `HuggingFaceVideoClient`, Android manifest,
model manifest, Gradle dependencies/version metadata, and GitHub Actions artifact
names. Native submodule commits were preserved.

## Limits still requiring infrastructure or device verification

- No isolated app-build worker is connected. Source generation/editing/versioning
  and ZIP export work; in-app APK/AAB compilation is explicitly unavailable.
- Private access for distribution needs user-specific authorization or a gateway.
  Personal credentials are not distributed in the APK. Provider switching is
  explicit; automatic fallback is not implemented.
- Space storage is currently ephemeral. Redeployments can discard remote jobs;
  unknown results are reported without duplicate generation. Save results locally.
- Citation helpers format known metadata; they are not a full CSL engine or a
  verification of generated prose. Read and verify the original sources.
- Device UI/media/PDF rendering, microphone lifecycle, OEM background restrictions,
  local model performance and very long transfers remain physical acceptance
  tests. Android force-stop suspends tracking until the app is reopened.
- Long video continuity and GPU quotas remain model/provider limitations.


Debug-install signing note: Android upgrades require the same signing certificate,
not just an increasing versionCode. This repository's hosted debug builds do not
retain a private signing keystore between fresh runners. The artifact includes
`APK-SIGNER.txt` so certificates can be compared. If Android rejects an update
because its signer differs, do not uninstall an app containing needed projects;
back up those projects first or rebuild with the original signing key. A stable
production signing setup is separate deployment work, and no private signing
material has been placed in this repository.
