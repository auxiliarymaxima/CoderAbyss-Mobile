# Coder Abyss

**Local AI. Real Creation. A Brighter Tomorrow.**

Coder Abyss is a mobile-first private AI creation environment.

Initial Android foundation:

- Kotlin
- Jetpack Compose
- Local-first interface
- Microphone permission support
- Whisper integration point
- Local model manager interface
- Qwen integration point
- Image model integration point
- Projects
- Library
- Settings
- GitHub Actions APK build
- GitHub Actions AAB build

The goal is for AI models and user projects to remain on-device whenever possible.
